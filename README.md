# FloraVision 🌿

FloraVision is a modern plant showcase website built using React.js and Tailwind CSS. The website is designed with a clean dark-themed UI inspired by modern glassmorphism design concepts. It provides users with an elegant platform to explore trendy indoor plants, view customer reviews, and interact with a simple shopping cart interface.

## Features

* Modern responsive UI design
* Dark green aesthetic theme
* Glassmorphism styled cards
* Product showcase section
* Customer review section
* Interactive navbar
* Plant type dropdown menu
* Search bar interaction
* Add to cart functionality
* Cart popup display
* Responsive layouts using Tailwind CSS

## Technologies Used

## Installation

Clone the repository:

```bash
git clone <repository-link>
```

Move into the project directory:

```bash
cd flora-vision
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the local server URL shown in the terminal.
